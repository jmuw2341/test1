# 네이버 카페 - 테슬라 카페 핸드폰 거치대 조사 정리

- 작성일: 2026-09-07
- 도구: Playwright MCP (브라우저 자동화)

## 1. 진행 과정

1. Playwright로 네이버 카페(cafe.naver.com) 접속 → 사용자 로그인 확인
2. 카페 검색에서 "테슬라" 검색 → 대표 카페 **★테슬라 [TKC] 모델S 모델3 모델X 모델Y 사이버트럭 FSD 전기차** (`cafe.naver.com/noljatravel`) 확인
3. 카페 내 **🛡️ TKC 통합 장터 [안전거래]** 게시판으로 이동
4. 게시판 내 검색어 "핸드폰 거치대"로 제목 검색 → 총 6건 검색됨
5. 가격 확인을 위해 게시글을 열람 시도했으나, 전체 게시글이 **카페 회원 전용(멤버 공개)** 글이라 본문(가격 포함) 열람 불가 → 카페 미가입 상태
